📚 BookBinder Brasil — Livreto

Transforma um PDF comum em cadernos prontos para encadernação artesanal.

Aplicativo desktop moderno, escrito em Python, com interface em Português. Funciona no Windows e no Linux, sem precisar de Java ou terminal.

🚀 Baixar

Escolha a versão para o seu sistema:

Baixar para Windows (.exe) Baixar para Linux (binário)

No Linux, após baixar, dê permissão de execução com: chmod +x bookbinder-brasil

✨ Funcionalidades

  • Interface em Português (PT-BR)
  • Detecção automática do tamanho do PDF
  • Presets de livro (A4→A5, A5→A6, 16x23 cm, etc.)
  • Impressão duplex (frente e verso)
  • Instruções de montagem automáticas
  • Recorte de margens brancas

📖 Como usar

  1. Baixe o executável para o seu sistema.
  2. Abra o programa e clique em "Abrir PDF..." (ou arraste o PDF para a janela).
  3. Escolha o Tamanho do livro e as Páginas por caderno (16 é o padrão).
  4. Clique em "Gerar cadernos".
  5. Na pasta de saída, você encontrará os PDFs prontos e um arquivo instrucoes_impressao.txt.
